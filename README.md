# 🧠 MNIST Handwritten Digit Dataset

## 📌 About Dataset

This dataset contains handwritten digit images from **0 to 9**. It is commonly used for handwritten digit recognition and image classification.

## 📊 Dataset Details

* **Total Images:** 70,000
* **Training Images:** 60,000
* **Testing Images:** 10,000
* **Image Size:** 28 × 28 pixels
* **Image Type:** Grayscale
* **Number of Classes:** 10
* **Classes:** 0–9

## 🔢 Data Representation

Each image contains pixel values ranging from **0 to 255**.

The `28 × 28` image can be represented as **784 pixel values**.

```text
28 × 28 = 784 pixels
```

The corresponding label represents the digit shown in the image.

## 🎯 Purpose

The dataset can be used for:

* Handwritten digit recognition
* Image classification
* Machine Learning
* Deep Learning
* Neural Network experiments
